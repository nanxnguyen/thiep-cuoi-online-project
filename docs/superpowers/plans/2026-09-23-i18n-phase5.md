# Phase 5 — Đa ngôn ngữ: plan

Spec: `docs/superpowers/specs/2026-09-23-i18n-phase5-design.md`. Task theo thứ tự phụ thuộc (BE trước vì FE schema mirror nó).

- [ ] **I1** BE: `InvitationContent.java` thêm `Couple.messageEn`, `Thanks.messageEn`, `Gift.noteEn`, `Question.labelEn` (mỗi record 1 compact constructor tự đổi `null`→`""`). `InvitationContentTest.java` thêm test: JSON thiếu 4 trường mới (giả lập thiệp `v:1` cũ) vẫn parse ra `""`, không lỗi validation. Verify: `./mvnw test`.
- [ ] **I2** FE: `lib/content.ts` thêm 4 trường vào `contentSchema`/`defaultContent`/`sampleContent`. `tests/content.test.ts` thêm assertion 4 trường mới = `""` ở default. Verify: `npm test`, `npm run typecheck`.
- [ ] **I3** Regenerate fixture BE dùng bởi test contract (README có lệnh `node -e`) — chỉ nếu có fixture cố định đang bị lệch sau I1/I2 (kiểm bằng chạy fixture-dependent test, không regenerate mù).
- [ ] **I4** `lib/i18n.ts` (mới, thuần) + `tests/i18n.test.ts`: `resolveLocale`, `t()`, dictionary vi/en đủ key cho chrome text (section heading, RSVP, đếm ngược, nhãn loại sự kiện chuẩn, toggle). Verify: `npm test`.
- [ ] **I5** `app/invite/[slug]/page.tsx`: đọc `sp.lang` → `resolveLocale`, truyền `locale` cho `InvitationRenderer`; `generateMetadata` thêm `alternates.languages` (giữ `to`/`g` nếu có). Verify: `npm run build`.
- [ ] **I6** `InvitationRenderer` + section components (`Couple`, `Thanks`, `Gift`, `RsvpSection`, `Family`, `Events`, `Album`, `CountdownSection`, `WishesSection`): nhận `locale?: Locale` (mặc định `"vi"`), dùng `t()` cho chrome + `pick()` cho 4 trường nội dung, nhãn loại sự kiện chuẩn lấy từ dictionary theo `kind`. Verify: `npm run typecheck`, `npm test`.
- [ ] **I7** `RsvpForm`/`RsvpSection`: câu hỏi dùng `labelEn` khi có + `locale==="en"`, fallback `label`. Verify: `npm test`.
- [ ] **I8** Component toggle ngôn ngữ nhỏ (link `?lang=vi`/`?lang=en`, giữ query khác) gắn vào trang khách (không phải nút client phức tạp). Verify: đọc code, không cần test riêng (pure link).
- [ ] **I9** Studio: `CouplePanel` thêm 2 `TextAreaField` (Lời mời bản Anh, Lời cảm ơn bản Anh, tuỳ chọn); `GiftPanel` thêm "Lời nhắn bản Anh"; `RsvpPanel` mỗi câu hỏi thêm ô "Bản Anh (tuỳ chọn)". Verify: `npm run typecheck`, `npm run build`.
- [ ] **I10** Full gate: `npm test`, `npm run typecheck`, `npm run build`, BE `./mvnw test`. Cập nhật `PROGRESS.md` (bảng %, mục trạng thái Phase 5, nhật ký). QA trình duyệt cuối phase theo quy ước (mở `?lang=en`, RSVP cả 2 ngôn ngữ, Lighthouse).
